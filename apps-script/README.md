# Формы Jazira → Google-таблица + Telegram

Сайт отправляет заявки (лист ожидания и отзывы) в веб-приложение Google Apps Script.
Оно пишет строку в таблицу и, если настроено, присылает уведомление в Telegram.
Токен бота хранится в свойствах скрипта — в код сайта и в git он не попадает.

## 1. Таблица и скрипт (5 минут)

1. Создайте Google-таблицу, например «Jazira — заявки».
2. В таблице: **Расширения → Apps Script**.
3. Сотрите содержимое `Код.gs` и вставьте весь файл [`Code.gs`](Code.gs). Нажмите 💾.

Листы `waitlist` и `feedback` скрипт создаст сам при первой заявке.

## 2. Telegram (по желанию)

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
   Можно взять и уже существующего своего бота.
2. Напишите своему боту любое сообщение (или добавьте его в группу, куда должны приходить заявки).
3. Узнайте **chat id**: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id":...}`. У групп id начинается с минуса.
4. В Apps Script: ⚙ **Настройки проекта → Свойства скрипта → Добавить свойство**:
   - `TG_TOKEN` — токен бота;
   - `TG_CHAT` — chat id.
5. Вверху выберите функцию `testTelegram` → **Выполнить** → разрешите доступ.
   В Telegram должно прийти «Проверка связи с сайтом Jazira».

## 3. Публикация

1. **Начать развертывание → Новое развертывание** → тип ⚙ **Веб-приложение**.
2. «Выполнять как» — **Я**, «У кого есть доступ» — **Все**.
3. **Развернуть** → скопируйте адрес, который заканчивается на `/exec`.
4. Проверка: откройте этот адрес в браузере — должно быть `{"ok":true,"service":"jazira-forms"}`.
5. Вставьте адрес в `CONFIG.formUrl` в [`assets/main.js`](../assets/main.js).

После правок `Code.gs`: **Начать развертывание → Управление развертываниями → ✏ → Версия: новая**.
Адрес `/exec` при этом не меняется.

## Что защищено

- Скрытое поле-ловушка: заявки от ботов, заполнивших его, молча отбрасываются.
- Не больше 30 заявок в минуту, длина полей ограничена (контакт 120, сообщение 1500 символов).
- Текст, начинающийся с `=`, `+`, `-`, `@`, сохраняется как текст, а не как формула.
- Если Telegram недоступен, заявка всё равно остаётся в таблице.

Логику можно проверить без Google: `node tools/test-apps-script.mjs`.
